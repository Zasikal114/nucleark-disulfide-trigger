## 1. 研究背景（第 1 栏，参考版）

湿实验同学可能已有成稿；以下为 dry 统一口径的参考版本，两栏数字与后文一致。

### 完整版

谷胱甘肽（GSH）在细胞内外存在约一千倍的浓度梯度：血液与细胞外液中仅 2–20 µM，而细胞质高达 1–10 mM（HeLa 细胞约 7 mM）；细胞核与细胞质处于高度还原状态（GSH/GSSG 达 30:1–100:1），内质网则明显更氧化（1:1–3:1）。这一梯度使二硫键成为理想的内源性"分子开关"——在血液循环中稳定存在，进入细胞后被 GSH 特异性断裂。

然而，现有二硫键设计多基于固定化学结构，响应阈值不可调：追求稳定性会导致目标区域内响应不足，追求敏感性则会在非目标区域提前激活。此外，当二硫键系统用于递送核酸类货物时，还必须同时回答"**结合住**（与核酸稳定结合并浓缩保护）、**运得到**（循环与细胞摄取中不解散）、**放得出**（到达目标区室后高效释放）"三个问题，这对分子设计提出了超出单一 GSH 响应性的功能要求。

本项目提出**基于空间可及性调控**的二硫键分子工程策略：通过系统改变二硫键邻近间隔区的结构参数（半胱氨酸位置、侧链位阻、连接子长度与刚性），构建覆盖"过于敏感 → 过于稳定"连续区间的分子库，并结合模块化的双链凝聚体设计（互作域 + 无序区 IDR + 核酸结合标签），把响应阈值从"单点"变为"可编程"。

### 精简版（约 170 字）

细胞内外 GSH 浓度相差约千倍（血液 2–20 µM，胞质 1–10 mM），使二硫键成为理想的还原响应开关；但现有设计响应阈值固定，难以兼顾稳定性与响应性。本项目提出基于**空间可及性调控**的二硫键分子工程：通过半胱氨酸位置、侧链位阻与连接子设计连续调节响应阈值，并构建"互作域 + IDR + 核酸结合标签"的模块化双链凝聚体，实现核酸货物的**结合—保护—响应释放**全流程可控。

## 2. 研究方法与内容（第 2 栏）

> 本栏是 dry 的主战场：按"设计思路 → 三个工具包的方法学选择与迭代"组织。
> 每个小节先给"为什么这么选"（方法学选择），再给"实践中改了什么"（方法学迭代）——这正是中期交流最想看到的。

### 2.0 总设计思路

**一句话**：把递送系统拆成三个可独立设计、可组合筛选的模块——

- **互作域（含链间二硫键）**：决定两条链能否正确配对、二硫键在哪里形成、以及 GSH 断裂的难易程度（响应阈值）；
- **IDR 相分离模块**：决定凝聚体形成的倾向与浓度窗口（装载能力）；
- **核酸结合标签（锌指阵列等）**：决定对核酸货物的结合特异性与结合量（货物抓取）。

三个模块分别对应三套 dry 工具包（见 2.1–2.3），总体架构与工作原理见图 figA：

> **图 figA（建议放第 2 栏上部，大幅）**：左半为构建体模块化设计（3 互作域 × 3 IDR 组合矩阵 + 可插拔核酸结合标签 + 空间可及性三参数），右半为 GSH 梯度驱动的"结合 → 断裂 → 释放"两态示意。
> 路径：`素材库/05_新绘示意图/figA_构建体架构与GSH响应原理.png`（300 dpi）

### 2.1 工具①：链间二硫键位点与响应电位预测

**方法学选择**——为什么用 AlphaFold-Multimer + FoldX：

- 链间二硫键能否形成是几何问题：用 AlphaFold-Multimer 预测双链复合物结构，对跨链半胱氨酸对按原子间距与构象阈值自动筛选位点；
- "断不断"要变成"多容易断"才可比较：对候选位点做 Cys→Ser 突变，用 FoldX 计算去除二硫键后的折叠自由能变化 ΔΔG，换算为氧化还原电位 E(V)——|E(V)| 越大，二硫键越难断裂，对应更高的 GSH 响应阈值。这一指标把"空间可及性"与"响应阈值"定量连接，是后续分子库与 QSAR 的核心自变量。

**方法学迭代**（实践中改了什么）：

1. 突变策略从 Cys→Ala 调整为 **Cys→Ser**：丝氨酸是天然蛋白中更常见的"去二硫键"中性替换，更接近真实还原态；
2. 结构依据从单一 AF 模型改为 **5 个 AF-Multimer 模型取一致性**，避免单模型构象噪声；
3. 交付形态从本地 Linux 脚本升级为 **网页工具 Foldx-EV**（Hugging Face Space，Docker 部署，Gradio 界面）：湿实验同学上传 CIF 即可批量获得 n.cys、ΔΔG 与 E(V)，不依赖本地方环境；
4. 以**胰岛素**（含经典二硫键、文献电位已知）作为工具的测试体系，校验计算流程合理性。⚠️（若需在海报写胰岛素基准的对比数值，需先跑完 benchmark 并与文献对照——目前仅有测试目录。）

### 2.2 工具②：相分离能力多预测器共识管线

**方法学选择**——为什么做"共识"而不信单一预测器：

相分离预测目前没有公认金标准，单一工具偏差大。管线并行调用六种外部预测器（IUPred2A、PSPredictor、catGRANULE2、FuzDrop、PhaSePred、PSPHunter），以 BLAST 映射 UniProt 获取注释，再锚定 LLPSDB / PhaSePro 中**已实测的相分离记录**——输出不只是"阳/阴性"，还包括匹配到的实验条件范围（蛋白浓度、盐、pH、温度），可直接指导湿实验复现条件。

**方法学迭代**：

1. 早期版本曾使用自建的本地加权评分，因权重无来源可溯被**整体弃用**：正式版坚持"所有分值来自外部预测软件、公开数据库或明确规则"，结果表中每个参数保留 `*_source` 溯源列；
2. 序列映射从单一 BLAST 升级为 **BLAST + MMseqs2/Smith-Waterman 双路交叉复核**，确认结论不依赖映射方式；
3. 数据诚信处理：FuzDrop 需要浏览器 token，无 token 时**记录为跳过而不伪造分数**（最终以有效 token 补齐了全部关键分值）。

### 2.3 工具③：核酸结合标签设计（ZF 罕见标签）

**方法学选择**——为什么设计"人基因组中罕见"的锌指识别标签：

项目需要核酸结合模块，但锌指阵列"结合过强"会带来安全性问题（活细胞内非特异结合宿主基因组）。设计目标因此定为两条：**安全性**（识别标签在人基因组中 0 位点）、**通用性**（可插入常见质粒骨架）。据此搭建八步全流程管线（见图 fig2）：

> **图 fig2（建议放第 2 栏或第 3 栏）**：ZF 罕见标签八步流程——全基因组 k-mer 计数 → 罕见 12-mer 筛选 → 独立验证 → CpG-free 过滤 → 锌指可构建性评分 → 载体兼容性检查 → 插入位点筛选 → 寡核苷酸设计。
> 路径：`素材库/02_ZF图表/fig2_workflow.png`

**方法学迭代**：

1. 筛选中发现"**0 位点**"与"**无 CpG**"两个约束互斥：0 位点标签几乎都含 CpG，而 CpG 在活细胞内会被甲基化干扰。决策：活细胞内使用 **CpG-free 候选集**（101 个可用候选）；
2. 全基因组 k-mer 计数用 **base-4 整数编码 + 双链合并**完成性能优化（3.1 Gb 基因组一次性扫描）；
3. 所有关键结论均用**独立脚本、原始字符串搜索**复核一遍，避免单一实现路径引入系统误差。

### 2.4 （可选）pDNA–蛋白结合预测器

一套把"结合多少"算出来的最小模型：给定质粒序列与蛋白结合 motif（默认 GCGTGGGCG），预测每个类 motif 位点的 Kd 与每质粒可结合蛋白层数，并计算相分离浓缩（局部浓度放大倍数）对结合的增益——直接对应"凝聚体如何提升核酸结合"的定量叙事。

> ⚠️ 口径注意：该模型原始叙事挂在"NLS 入核增强"上，本海报已按约定剔除入核表述；若设计人觉得第 3 栏已满，本小节可整段删除，不影响主线。

### 3.1 成果①：二硫键氧化还原电位计算工具已上线

- **Foldx-EV**（Hugging Face Space）：网页上传 CIF → 自动输出 n.cys、Cys→Ser ΔΔG 与 E(V)，支持批量处理，全流程脚本可复现；

> 建议配图：Foldx-EV 网页截图（素材库 `03_二硫键工具/` 内附截图指引与链接）。

### 3.2 成果②：9/9 双链构建体预测通过相分离筛选，且锚定实测条件

对"3 互作域（SH3 / PDZ3 / Myc-LZ）× 3 IDR（TDP43 / CPEB2 / MLLT1）"的组合矩阵共 9 个双链构建体完成预测：**全部判定 LLPS 阳性、全部可形成链间二硫键**；FuzDrop p(LLPS) 0.94–0.9995，PSPredictor 0.84–0.999。其中 TDP43 族与 MLLT1 族在 LLPSDB 中存在实测记录锚定：

### 3.3 成果③：ZF 罕见识别标签全流程交付

- 从 16.7M 序列空间中筛出 **22,378 个人基因组 0 位点 12-mer**（独立脚本复核）；
- CpG-free 过滤得 **101 个可用候选**（活细胞内避免甲基化干扰）；
- 推荐标签 **GGTCCACTACTA**：人基因组精确位点从现有靶的 3,462 个降至 **31 个（结合位点数下降约 112 倍）**，1 错配邻域同步改善约 85 倍；
- **15 种常用质粒骨架 × 250 个标签变体全部 0 命中**（含慢病毒包装系统 psPAX2 / pMDLg-pRRE / pRSV-Rev / VSV-G），大肠杆菌 K-12 基因组亦不构成约束（推荐标签 0 位点 vs 现有靶 91 个）；
- 依托普林斯顿 B1H 指模库（64 三联体全覆盖）完成**锌指可构建性评分，给出 4 指阵列**（GGTCCACTACTA → RKWTLDL / RKWTLDL / RREHLTL / HLTTLRR）；
- 最终输出 **24 个安全插入位点**与 **1,080 条可直接订购的寡核苷酸序列**，全流程脚本可复现。

## 4. 未来研究计划（第 4 栏）

### 完整版

1. **空间可及性分子库与动力学表征**：系统构建改变 Cys 位置 / 侧链位阻 / 连接子参数的二硫键变体库，在模拟生理与病理 GSH 梯度下测定断裂半衰期、速率常数与选择性指数，建立"间隔区结构—空间可及性—响应阈值"的定量关系；
2. **QSAR 与主动学习闭环**：提取各变体 1D–3D 结构特征（SASA、局部柔性、位阻体积等）与动力学参数关联建模，通过"预测—实验验证—模型迭代"逐步实现按目标阈值反向设计二硫键；
3. **多层级细胞验证**：以 rxYFP 传感器实时监测胞内 GSH、以 BSO 耗竭构建 GSH 梯度细胞系（HEK293T / WB-F344），共成像追踪二硫键断裂与货物释放的时空过程；
4. **核酸结合方向的延伸**：对 ZF 标签开展湿实验验证（EMSA / 足迹法确认结合特异性与"人基因组 0 位点"性质），并把 pDNA 结合预测器与凝聚体浓缩模型对接，量化"结合层数—释放效率"关系；
5. **工具包整合封装**：把二硫键位点预测、E(V) 计算、相分离共识预测与标签设计整合为一站式设计平台，对外提供网页入口。

### 精简版（约 130 字）

下一步：① 构建改变 Cys 位置 / 侧链位阻 / 连接子的二硫键变体库，在 GSH 梯度下测定断裂半衰期与选择性指数，建立"间隔区结构—响应阈值"定量关系；② 以 QSAR + 主动学习实现按目标阈值反向设计；③ 在 GSH 梯度细胞系中验证断裂特异性；④ 对 ZF 标签开展 EMSA/足迹验证，并整合四大模块为一站式二硫键设计平台。
